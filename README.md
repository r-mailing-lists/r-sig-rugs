# r-sig-rugs

Starting and organizing R user groups

Automated mbox archive. Updated daily via GitHub Actions.

## Structure

- `raw/` - Monthly .mbox files downloaded from [https://stat.ethz.ch/pipermail/r-sig-rugs/](https://stat.ethz.ch/pipermail/r-sig-rugs/)
- `processed/` - Structured JSON output from rmail-parser
- `meta.json` - List statistics
